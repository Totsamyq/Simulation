# Симуляция

Пошаговая симуляция 2D мира, населённого травоядными и хищниками. Мир также содержит ресурсы (траву) и статичные объекты (камни, деревья).

Проект выполнен в рамках курса [zhukovsd IT-Community](https://zhukovsd.github.io/java-backend-learning-course/projects/simulation/).

## Как это работает

Мир представлен матрицей `N x M`, каждая клетка занята не более чем одной сущностью. На старте карта заполняется случайным образом: травоядные, хищники, трава, камни и деревья. Каждый ход:

- травоядные ищут ближайшую траву и либо двигаются к ней, либо съедают её, если она рядом;
- хищники ищут ближайшее травоядное и либо двигаются к нему, либо атакуют, нанося урон;
- если травы на карте становится мало — она пополняется в случайных свободных клетках.

Поиск пути реализован с нуля через обход в ширину (BFS), с учётом препятствий (камни и деревья непроходимы).

## Архитектура

- **`Entity`** — корневой абстрактный класс всех сущностей мира. Хранит позицию (`Position`) и внешний вид.
- **`Position`** — неизменяемый класс координат `(x, y)` с переопределёнными `equals()`/`hashCode()`, используется как ключ в `Map`.
- **`Grass`, `Tree`, `Rock`** — ресурс и статичные препятствия.
- **`Creature`** (абстрактный) — общий предок существ: HP, скорость, абстрактный метод `makeMove()`.
- **`Herbivore`, `Predator`** — травоядное и хищник, каждый со своей логикой хода.
- **`Map`** — хранилище состояния мира (`HashMap<Position, Entity>`), инкапсулирует все изменения через методы `addEntity`/`removeEntity`/`moveEntity`, отдаёт списки существ по видам.
- **`PathFinder`** — поиск пути (BFS), общий для травоядных и хищников.
- **`Action`** (абстрактный) — единица поведения мира. Наследники: `PopulateMapAction` (расстановка при старте), `MoveCreaturesAction` (ход существ), `ReplenishGrassAction` (пополнение травы).
- **`Simulation`** — управляет циклом симуляции: выполняет `initActions` один раз, затем `turnActions` каждый ход.
- **`Renderer`** — консольная отрисовка карты.

## Запуск

Точка входа — `main()`. Симуляция настраивается через параметры `PopulateMapAction` (количество каждого вида) и `ReplenishGrassAction` (порог пополнения травы).

## Что можно улучшить

- Учёт `speed` при движении (сейчас все существа двигаются на одну клетку за ход)
- Более гибкий поиск цели в `PathFinder` через `Class<?>`/`Predicate` вместо `instanceof`
- Механики размножения и голода
